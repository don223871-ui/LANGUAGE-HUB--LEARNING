# LANGUAGE HUB · LEARNING — PROJECT CHECKPOINT 01

## Current Architecture

### Home
The Home page is the master entry point.

### Three Core Platforms
1. **Language Skills** — what the learner can do with language.
2. **Language Systems** — the knowledge and patterns that make language usable.
3. **Language Competence** — how language knowledge and skills become effective performance.

## Platform-Level Areas

### 03 · Language Competence

- Strategic Competence

## Navigation Standard

Every page must contain the same circular floating global navigation:

- **MB Logo** → Home / Hub
- **Home** → Home
- **📚 Language Skills** → Skills platform
- **⚙️ Language Systems** → Systems platform
- **🎯 Language Competence** → Competence platform

Inside each platform, local navigation must also be available:

- **Previous** → previous area in the current platform
- **Next** → next area in the current platform

## Development Rule

We are currently designing the architecture before developing detailed content.

The workflow is:

**Platform → Main Area → Sub-skills / Sub-areas → Learning Content → Practice → Performance → Transfer → Assessment**

No detailed sub-skill content should be added until the corresponding main-area map has been agreed.

## Next Development Stage

Build the detailed architecture of each main area one at a time, beginning with the first selected area under Language Skills.
